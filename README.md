# Mi organizador

Organizador de tareas con planificador semanal. Es una web app de un solo archivo (`index.html`) que se puede añadir a la pantalla de inicio en Android e iOS. Los datos se guardan en el navegador (localStorage).

## Funciones

- Vista semanal con progreso y tareas por franja (mañana, tarde, noche)
- Bandeja de tareas sin día
- Prioridad (alta, media, baja) y categorías (trabajo, estudio, casa, personal)
- Lista de todas las tareas con filtro por categoría

## Publicar con GitHub Pages

1. En el repositorio, ve a **Settings → Pages**.
2. En **Source**, elige **Deploy from a branch**, rama `main` y carpeta `/ (root)`.
3. Guarda. En un par de minutos la app estará en `https://braabidi.github.io/organizador-de-tareas/`.

## Añadir a la pantalla de inicio

- **iPhone (Safari):** botón Compartir → «Añadir a pantalla de inicio».
- **Android (Chrome):** menú ⋮ → «Añadir a pantalla de inicio» / «Instalar app».
